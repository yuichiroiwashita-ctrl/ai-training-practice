# AI研修 練習ページ（架空）

AI研修（Claude編）の、Chrome拡張のハンズオン用の練習ページ。内容はすべて架空（メールは example.com、電話は 03-0000-0000 台）。
公開URL: https://yuichiroiwashita-ctrl.github.io/ai-training-practice/

| ファイル | 内容 |
|---|---|
| `index.html` | 一覧 |
| `form.html` | 練習用の問い合わせフォーム（送信してもどこにも送られない） |
| `company.html` | 会社情報（フォームに入れる内容の元データ） |
| `product-a.html` / `product-b.html` | 比較表用の商品ページ2つ |
| `news.html` | 要約用の架空ニュース記事 |

元データは、研修資料のリポジトリ（ai-training-slides）の `decks/claude/materials/フォーム練習/`。
